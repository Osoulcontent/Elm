# آفاق تعاون

مقترح شراكة بين شركة آفاق المستقبل وشركة عِلم، بخبرة جمعية أصول للمحتوى الدعوي، لخدمة مبادرات رابطة العالم الإسلامي.

## محتويات المستودع

- `index.html`: الصفحة كاملة (الخطوط تُحمَّل من Google Fonts).
- `assets/img/`: الصور والشعارات بصيغة WebP.
- `.nojekyll`: يجعل GitHub Pages ينشر الملفات كما هي.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub، وارفع إليه محتويات هذا المجلد كما هي (مع مجلد `assets`).
2. من **Settings ← Pages**، اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واحفظ.
3. بعد دقيقة أو دقيقتين تظهر الصفحة على الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## تعديل المحتوى

النصوص كلها داخل `index.html`. أغلب الأقسام نص HTML مباشر، أما المسارات والمشروعات الخمسة وأقسام «منهاج» وأغلفة المكتبة فبياناتها في الجزء البرمجي أسفل الملف (المصفوفات `TRK` و`PRJ` و`MZ` و`LIB`).
